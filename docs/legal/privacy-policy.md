# 개인정보처리방침 (초안)

> **초안입니다.** 2026-11-16 기준 코드에서 실제로 저장하는 항목을 근거로 썼습니다. 법률 검토를 거치지 않았습니다.
> `【작성 필요】` 표시는 운영자가 정해서 채워야 합니다. 앱스토어·플레이스토어 제출에는 이 내용을 공개 URL로 올려야 합니다.
> 기능이 바뀌어 저장 항목이 달라지면 이 문서도 함께 고쳐야 합니다(근거 위치는 각 항목 옆에 적었습니다).

슈엔증권(이하 "서비스")은 이용자의 개인정보를 「개인정보 보호법」에 따라 처리하며, 다음과 같이 처리방침을 둡니다.
서비스는 게임을 가상 종목으로 다루는 **모의 투자 교육용 서비스**이며, 실제 돈·주식·결제 정보를 다루지 않습니다.

## 1. 처리하는 개인정보 항목과 목적

| 구분 | 항목 | 목적 | 근거 위치 |
|---|---|---|---|
| 회원 가입·로그인 | 이메일, Firebase 사용자 식별자(Google 계정 연동 시 Google 식별자), 이메일 로그인 시 비밀번호(비밀번호는 Firebase Authentication이 보관하며 서비스 DB에는 저장하지 않음) | 본인 확인, 계정 유지 | `users`(email, google_uid), Firebase Authentication |
| 프로필 | 닉네임, 프로필 사진(직접 올린 경우)·Google 프로필 사진 주소 | 랭킹·토론 등 서비스 내 표시 | `users`(nickname, profile_image_url), `profile_photos` |
| 서비스 이용 기록 | 모의 주문·체결·정산 내역, 모의 자산, 관심 종목, 가격 알림, 출석·미션·칭호, 대출, 퀀트 전략, 예측·탭 베팅 기록 | 모의 거래 제공, 랭킹 산정 | `orders`, `trades`, `settlements`, `portfolios`, `user_watchlists`, `price_alerts` 등 |
| 이용자 작성물 | 종목 토론 글·댓글·태그, 전광판 메시지, 신고 내용 | 커뮤니티 기능 제공, 신고 처리 | `stock_discussions`, `stock_comments`, `stock_talk_posts`, `billboard_messages`, `user_reports` |
| 외부 API 이용 시 | API 키(해시), 주문 요청 기록 | OpenAPI 제공, 중복 요청 방지 | `open_api_keys`, `open_api_requests` |
| 운영·보안 | 접속 IP(요청 처리 중 호출 한도 계산에만 사용하고 저장하지 않음), 이용 제한 기록·사유 | 부정 이용 방지 | `users`(trade_banned_until, trade_ban_reason), 관리자 감사 기록 |

서비스는 주민등록번호, 실명, 연락처, 결제 정보를 수집하지 않습니다.

## 2. 보유 기간

- 회원 정보와 이용 기록: 회원 탈퇴 시까지. 【작성 필요: 탈퇴 후 즉시 삭제할지, 분쟁 대비 보관 기간을 둘지】
- 종목 실시간 대화(`stock_talk_posts`): 작성 후 7일이 지나면 자동 삭제(`StockTalkService.RETENTION`).
- 봇 거래·가격 세부 기록 등 운영 데이터: 서비스의 데이터 정리 정책에 따라 주기적으로 삭제(`DataRetentionService`).
- 백업: 매일 생성, 최근 7일분 보관(`docs/oci-operations.md`).

## 3. 개인정보의 제3자 제공

서비스는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 따라 요구되는 경우는 예외로 합니다.

## 4. 처리 위탁 및 국외 이전

| 수탁자 | 위탁 업무 | 이전 국가 |
|---|---|---|
| Google LLC (Firebase Authentication, Firebase Hosting) | 로그인 처리, 웹 화면 제공 | 【작성 필요: 미국 등】 |
| Oracle (Oracle Cloud Infrastructure) | 서버·데이터베이스 운영 | 【작성 필요: 사용 중인 OCI 리전의 국가】 |

## 5. 이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보를 조회·수정·삭제하거나 처리 정지를 요구할 수 있습니다.

- 닉네임·프로필 사진: 서비스의 설정 화면에서 직접 수정할 수 있습니다.
- 모의 자산 초기화: 계정 초기화 기능으로 할 수 있습니다.
- 회원 탈퇴·개인정보 삭제: 【작성 필요: 현재 서비스에 탈퇴 기능이 없습니다. 탈퇴 기능을 만들지, 아래 연락처로 요청받아 처리할지 정해야 합니다】

## 6. 파기 절차와 방법

보유 기간이 끝났거나 처리 목적을 달성한 개인정보는 지체 없이 데이터베이스에서 삭제합니다. 백업에 남은 정보는 백업 보관 기간(7일)이 지나면 함께 사라집니다.

## 7. 안전성 확보 조치

- 전송 구간 암호화(HTTPS·WSS), 웹 응답 보안 헤더 적용
- 비밀번호는 서비스가 직접 저장하지 않고 Firebase Authentication에 맡김
- 데이터베이스 접근 권한 제한, 백업 파일 접근 제한
- 관리자 작업 감사 기록

## 8. 쿠키 등 자동 수집 장치

서비스는 광고·추적 쿠키를 쓰지 않습니다. 로그인 상태 유지와 화면 설정(밝기, 탭 선택 등)을 위해 브라우저 저장소(localStorage, IndexedDB)를 사용하며, 브라우저 설정에서 지울 수 있습니다.
