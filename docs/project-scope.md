# 졸업 프로젝트 기능 범위

## 발표에서 반드시 보여줄 핵심 흐름

```text
게임 뉴스 수집·필터링
  → 감성·영향도 분석
  → 사람·봇 주문
  → 호가·체결·VWAP
  → 최종 가상 주가
  → 뉴스·거래·호가 근거와 변동 이유 표시
```

이 흐름이 졸업 프로젝트의 평가 단위다. 주문·체결·봇은 단순한 주식 연습 장치가 아니라 집단 투자 행동을 가격에 반영하는 시장 구성 요소로 설명한다.

## 기능 우선순위

| 우선순위 | 범위 | 발표 상태 |
| --- | --- | --- |
| P0 | 로그인, 닉네임, 메뉴, 랭킹, 마이페이지 | 완료 |
| P1 | 뉴스·가격 이유, 뉴스 영향도, 관련성 필터 | 완료 |
| P2 | 주문·체결·봇·호가·가격 형성 모델 | 완료 |
| P3 | 테스트·정합성·성능·재시작 복구·배포 문서 | 검증 진행 후 완료 처리 |
| 부가 | 시즌, 미션, 공유 카드 | 핵심 검증 뒤 추가 |
| 부가 | 한강 수온, 인생 리셋, 출석 보상 | 핵심과 분리해 소개 |

## 완료 판단 기준

- 뉴스가 종목과 관련 있는지 설명할 수 있다.
- 뉴스 방향과 거래·호가가 최종 가격으로 이어지는 과정을 한 화면에서 확인할 수 있다.
- 같은 입력 데이터와 시드에서 봇 흐름을 재현할 수 있다.
- 주문 체결·자산·호가 원장이 서로 어긋나지 않는다.
- 처음 설치하는 사람이 환경변수와 실행 순서를 따라 할 수 있다.

시즌제·미션·공유 카드는 반복 이용을 늘릴 수 있지만, 핵심 가격 형성 흐름을 가리지 않을 때만 채택한다. 실제 사용자의 반응을 확인하기 전에는 보상이나 수익성을 확정적으로 약속하지 않는다.
