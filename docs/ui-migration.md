# 첨부 프론트엔드 UI 이식

기준: `ssokdex-frontend.zip`의 `ssokdex/`, GitHub `main`의 `b7c3a1a`.
확인일: 2026-10-02.

## 적용

- `src/styles/tokens.css`, `base.css`, `app.css`는 첨부본과 바이트 단위로 같다.
- 홈, 시장 목록과 옆 상세 화면, 속보, 내 계좌는 첨부본의 컴포넌트 구성을 사용한다.
- 로고와 게임 이미지는 첨부본 에셋을 사용한다. 서버의 니케 코드 `GOV`는 첨부본의 `nk.jpg`에 연결한다.
- 예전 화면의 전역 스타일 대신 원본 스타일을 불러온다. 기존 호가·차트·계정 관리 스타일은 `exchange-tools.css`의 `.integration-tools` 내부로 제한한다.
- Spring Boot 조회, Firebase 인증, 관심종목, 실제 주문 API를 유지한다. 간단 주문은 비동기 서버 응답을 기다린다.
- 원본 계좌와 상세 화면의 체결 표에는 `/api/settlements`의 수량·총 체결금액·시각을 연결한다.
- 앱의 Firebase custom token 이벤트 처리는 화면과 독립적인 `AuthBridge`로 옮겼다.

## 첨부본과 다른 부분

첨부본은 브라우저 내부 시뮬레이터이고, 이 프로젝트는 서버 데이터를 사용한다. 종목 수, 시세, 차트 경로, 뉴스, 자산과 체결 기록은 같지 않을 수 있다. 임의의 샘플 종목이나 뉴스로 서버 데이터를 대체하지 않는다.

첨부본에 없는 호가·지정가 주문·상세 차트와 계정 관리·미체결 주문·미션·가격 알림은 접힌 추가 기능으로 유지한다. 원본의 랭킹 페이지는 안내 문구뿐이므로, 실제 랭킹 API를 유지하고 원본의 표 스타일로 표시한다. 인증이 필요한 계좌는 기존 인증 규칙을 따른다. 기본 테마는 첨부본의 밝은 테마다.

## 검증

- 타입 검사와 배포 빌드 통과.
- 원본 CSS 3개 파일의 바이트 일치 확인.
- 로컬 백엔드 `/api/health` 정상 응답, 공개 시세 조회 확인.
- Chrome에서 원본과 이식 결과의 홈·시장 상세 화면 확인.
- 시장 검색 및 종목 상세 이동 확인.
- 390px 화면에서 상세 정보가 시세표 위로 이동하며 문서 가로 넘침이 없음을 확인.
- 내 계좌, 서버 랭킹, 속보의 실제 화면 확인.
- 추가 거래 도구를 펼쳐 실제 호가·기록 차트·지정가 입력 폼 표시 확인. 펼친 화면도 가로 넘침과 중복 HTML ID 없음.

로그인 신규 수행, 주문 접수·체결·취소, 계좌 초기화, 모바일 앱 네이티브 인증과 외부 배포는 이번 검증에 포함하지 않는다. UI 검증 중 사용자 계좌의 주문이나 초기화를 실행하지 않았다.

작업 시작 전 로컬 `src`는 `.run.local/ui-before-transplant`에 보존했다. GitHub 푸시와 배포는 수행하지 않았다.
